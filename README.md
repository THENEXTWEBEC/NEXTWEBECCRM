# NextWebEC CRM

CRM interno para el equipo comercial de NextWebEC, construido con HTML, CSS, JavaScript y Supabase.

El proyecto está deliberadamente en **Fase 1**: arquitectura, esquema de datos, políticas RLS y documentación de seguridad. Consulta [la arquitectura de Fase 1](docs/phase-1-architecture.md) y aplica la migración de Supabase antes de comenzar la interfaz de Fase 2.
